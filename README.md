# My First Chrome Extension

Extension mẫu cho Chrome: **Đổi màu nền trang web** chỉ với một cú click.

## Tính năng
- Chọn màu bất kỳ từ bảng màu.
- Áp dụng màu nền cho trang hiện tại.
- Reset nhanh về màu trắng.
- Giao diện popup đẹp mắt, responsive.

## Cài đặt (cho nhà phát triển)
1. Tải hoặc clone repo này về máy.
2. Mở Chrome, truy cập `chrome://extensions/`.
3. Bật **Developer mode** (góc trên bên phải).
4. Nhấn **Load unpacked** và chọn thư mục dự án.
5. Extension sẽ xuất hiện trên thanh toolbar.

## Sử dụng
- Click vào icon extension trên thanh công cụ.
- Chọn màu hoặc nhập mã HEX.
- Nhấn "Áp dụng ngay" để thay đổi màu nền của trang web đang mở.
- Nhấn "Reset về trắng" để trở lại màu trắng mặc định.

## Công nghệ
- Manifest V3
- HTML, CSS, JavaScript
- Chrome Extensions API (scripting, tabs, storage)
